# Cost-Sweep Figure Notes

- **Data source:** `outputs/cost_sweep.csv`, generated by the executed `src.run_baseline_analysis` computation. The plotting script reads the CSV and checks each strict-interior mixed probability against the saved NashPy vectors and analytical cross-check columns.
- **Generation command:** From the project root, run `.venv/bin/python scripts/generate_cost_sweep_figure.py`.
- **Interpretation:** For fixed V = 4, the verified strict-interior mixed-equilibrium probability of Research is plotted only for the checked costs c = 1, 2, 3. The c = 0 and c = V = 4 boundaries are marked but have no ordinary interior mixed point; c = 5 is a high-cost case outside the interior.
- **Evidence limit:** This is a figure of equilibria in the formal game. It is not an empirical measure of LLM or human behavior, and it does not establish educational effectiveness.
