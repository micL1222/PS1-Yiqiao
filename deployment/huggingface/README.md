# Who Pays to Know?

Historical Gradio staging package. It was never deployed; the author manually uploaded the final Static Space from `deployment/huggingface-static/`.

This interactive tool illustrates a formal game-theoretic model. It does not report observed human or LLM behavior.

Educational effectiveness has not been evaluated.

The baseline has two agents choosing Research or Skip, information value V = 4, and private research cost c = 2. The interface uses unchanged copies of the verified project model and demo logic. No field-trip photos, paper files, or review material are part of this package.
