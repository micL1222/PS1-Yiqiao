# Who Pays to Know?

**Working title:** Who Pays to Know? Strategic Information Acquisition Before AI Collective Decisions

## Project Status

This repository is the clean v2 workspace for a revised COMSCI/ECON 206 PS1 research proposal.

**Current status:** Project initialized; theoretical baseline specified; computational verification not yet run.

## Research Question

When information is costly but collectively valuable, when will AI agents acquire information themselves rather than free-ride on others, and how closely will computational or observed behavior match the game-theoretic prediction?

## Interdisciplinary Structure

- **Economics:** Strategic information acquisition, private research costs, free-riding, and Nash equilibrium.
- **Computer Science:** Reproducible computational game analysis, equilibrium verification, parameter sweeps, and a later interactive implementation.
- **Behavioral Science:** Bounded strategic reasoning, beliefs about other agents, and possible deviations from equilibrium predictions.

## Baseline Game

Agents A and B each choose **Research (R)** or **Skip (S)**. If either agent researches, both receive information value **V = 4**. Each researching agent privately pays **c = 2**. If both skip, both receive 0. Payoffs are ordered (Agent A, Agent B).

| Agent A \ Agent B | Research (R) | Skip (S) |
| --- | --- | --- |
| **Research (R)** | (2, 2) | (2, 4) |
| **Skip (S)** | (4, 2) | (0, 0) |

The **theoretically predicted** pure-strategy Nash equilibria are **(Research, Skip)** and **(Skip, Research)**. These are theoretical predictions awaiting computational verification, not verified NashPy results.
