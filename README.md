## Research Question

When information is costly but collectively valuable, when will AI agents acquire information themselves rather than free-ride on others, and how closely will observed behavior match the formal game-theoretic prediction? The observed-behavior part is unanswered.

## Interdisciplinary Structure

- **Economics:** Strategic information acquisition, private research costs, free-riding, and Nash equilibrium.
- **Computer Science:** Reproducible computational game analysis, equilibrium verification, parameter sweeps, and a later interactive implementation.
- **Behavioral Science:** Bounded strategic reasoning, beliefs about other agents, and possible deviations from equilibrium predictions.

## Baseline Game

Agents A and B each choose **Research (R)** or **Skip (S)**. If either agent researches, both receive information value **V = 4**. Each researching agent privately pays **c = 2**. If both skip, both receive 0. Payoffs are ordered (Agent A, Agent B).

| Agent A \ Agent B | Research (R) | Skip (S) |
| --- | --- | --- |
| **Research (R)** | (2, 2) | (2, 4) |
| **Skip (S)** | (4, 2) | (0, 0) |

The author initially **theoretically predicted** the pure-strategy Nash equilibria **(Research, Skip)** and **(Skip, Research)**. The independent best-response checker and NashPy subsequently verified both for V = 4, c = 2.

## Verified Computational Baseline

For V = 4 and c = 2, the executed code generated Agent A payoffs `[[2, 2], [4, 0]]` and Agent B payoffs `[[2, 4], [2, 0]]`. Direct best-response enumeration and NashPy both returned the two initially predicted pure equilibria. NashPy additionally returned the symmetric mixed equilibrium **A = [0.5, 0.5], B = [0.5, 0.5]** in [Research, Skip] order. The later analytical cross-check, `p(Research) = 1 - c/V`, agrees at 0.5 for each player.

The cost sweep holds V = 4 and checks c = 0 through 5. See `outputs/verification_summary.md` for the generated results and boundary cautions. These calculations describe the formal game; they are not observations of real AI or human behavior.

## Reproducibility

From the project root, create the local environment and install the declared dependencies with `python3 -m venv .venv` and `.venv/bin/python -m pip install -r requirements.txt`. The tested environment was Python 3.9.6, numpy 2.0.2, nashpy 0.0.41, pandas 2.3.3, and matplotlib 3.9.4; `requirements.txt` remains unpinned.

Run the automated tests with `.venv/bin/python -m unittest discover -s tests -v`, and regenerate the baseline and cost-sweep outputs with `.venv/bin/python -m src.run_baseline_analysis`. The executed notebook is `notebooks/information_acquisition_baseline.ipynb`; it imports the same reusable source implementation. Exact tested versions and generated outputs are also recorded in `outputs/verification_summary.md` and `outputs/baseline_equilibria.json`.

## Interactive Educational Prototype

The local [Gradio prototype](demo/README.md) has two tabs: **Play One Strategic Decision** compares Agent A's selected payoff with a unilateral change, and **Explore the Full Game** shows the payoff matrix and equilibrium calculations. It reuses `src/information_acquisition_game.py` through `demo/demo_logic.py`. Run it locally with `.venv-demo/bin/python -m demo.app`; it binds to `127.0.0.1:7860` with `share=False`. The prototype passed logic tests and a localhost HTTP smoke check. It illustrates a formal model. It does not simulate or measure real LLM or human behavior, and educational effectiveness has not been evaluated.
